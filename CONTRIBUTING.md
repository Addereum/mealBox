# Contributing to MealBox 🍱

*(Deutsche Version unten / German version below)*

First off, thank you for considering contributing to MealBox! ❤️ 
This project is built for and by neurodivergent people (ADHD, Autism, Depression). We value a low-stress, pressure-free environment. Whether you want to fix a bug, translate a file, or suggest a new feature, your help is incredibly appreciated.

## 🧠 Our Philosophy
- **No Pressure:** Take your time. If you claim an issue and can't finish it due to lack of energy or time, that is 100% okay. Just let us know, no questions asked.
- **Anti-Slop Design:** We prefer clean, low-stimulus UIs without harsh shadows, chaotic animations, or bright clashing colors. We embrace standardized squircle shapes.
- **Accessibility First:** Features should be simple and easy to use on low-energy days (low executive function).

## 🛠️ How to start developing
1. **Prerequisites:** Make sure you have [Flutter](https://flutter.dev/docs/get-started/install) installed.
2. **Clone the repo:** `git clone https://github.com/Addereum/mealBox.git`
3. **Install dependencies:** `flutter pub get`
4. **Generate translations:** We use `flutter gen-l10n`. Run this command every time you add strings to the `.arb` files.
5. **Run the app:** `flutter run`

## 📝 Pull Request Process
1. Fork the repository and create your branch from `testing` or `master`.
2. Make your changes and test them locally.
3. If you've changed the UI, please attach a screenshot or short video to the PR.
4. Submit your Pull Request and we will review it as soon as we have the energy for it!

# Mitmachen bei MealBox 🍱

Zuerst einmal: Danke, dass du darüber nachdenkst, MealBox zu unterstützen! ❤️
Dieses Projekt wurde von und für neurodivergente Menschen (ADHS, Autismus, Depressionen) entwickelt. Wir legen Wert auf eine stressfreie Umgebung ohne Druck. Egal ob du einen Fehler beheben, die App übersetzen oder eine neue Funktion vorschlagen möchtest – deine Hilfe ist unglaublich wertvoll.

## 🧠 Unsere Philosophie
- **Kein Druck:** Lass dir Zeit. Wenn du ein Issue übernimmst und es wegen fehlender Energie oder Zeit nicht beenden kannst, ist das zu 100% okay. Sag einfach Bescheid.
- **Anti-Slop Design:** Wir bevorzugen saubere, reizarme Benutzeroberflächen ohne harte Schatten, chaotische Animationen oder grelle Farben. Wir mögen sanfte Abrundungen (Squircles).
- **Barrierefreiheit (Accessibility) zuerst:** Funktionen sollten extrem einfach und auch an Tagen mit wenig Energie (niedrige exekutive Funktion) nutzbar sein.

## 🛠️ So startest du mit der Entwicklung
1. **Voraussetzungen:** Stelle sicher, dass [Flutter](https://flutter.dev/docs/get-started/install) installiert ist.
2. **Repo klonen:** `git clone https://github.com/Addereum/mealBox.git`
3. **Abhängigkeiten installieren:** `flutter pub get`
4. **Übersetzungen generieren:** Wir nutzen `flutter gen-l10n`. Führe das aus, wenn du `.arb`-Dateien änderst.
5. **App starten:** `flutter run`

## 📝 Pull Request Prozess
1. Forke das Repository und erstelle deinen Branch basierend auf `testing` oder `master`.
2. Nimm deine Änderungen vor und teste sie lokal.
3. Falls du die Benutzeroberfläche geändert hast, hänge bitte einen Screenshot oder ein kurzes Video an den PR an.
4. Reiche deinen Pull Request ein! Wir schauen ihn uns an, sobald wir die Energie (Spooons) dafür haben!
