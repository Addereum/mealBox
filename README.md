MealBox 🍱
==========

**Eine einfache, wertfreie App zum Tracken von Mahlzeiten für Menschen mit ADHS, Autismus, Depressionen oder alle, die Schwierigkeiten mit regelmäßigem Essen haben.**

Lizenz: GPL-3.0
PRs willkommen 
Flutter 3.0+

🌟 Warum MealBox existiert
--------------------------

Essen zu vergessen ist eine häufige Herausforderung für Menschen mit:

*   **ADHS** (Zeitblindheit, exekutiven Dysfunktionen)
*   **Autismus** (Interozeptionsschwierigkeiten, Routinestörungen)
*   **Depressionen** (niedrige Energie, Appetitverlust)
*   **Angststörungen**
*   **Essstörungen** (als unterstützendes Tool neben professioneller Behandlung)
*   **Vielbeschäftigte Berufstätige** und **Studierende**
*   **Chronischen Erkrankungen**, die den Appetit beeinflussen

Die meisten Ernährungstracker konzentrieren sich auf Kalorien, Gewichtsverlust oder komplexe Nährwertangaben. MealBox ist anders: **Sie trackt nur eine Sache: Hast du deinen Körper heute genährt?**

✨ Funktionen
------------

*   **Ein-Klick-Protokollierung** - Einfach antippen, um eine Mahlzeit zu loggen
*   **Einfache Kategorien** - Frühstück, Mittagessen, Abendessen, Snack
*   **Kein Schulddesign** - Nur positive Bestärkung, keine Beschämung
*   **Lokale Speicherung** - Deine Daten bleiben sicher auf deinem Gerät
*   **Tageshistorie** - Sieh auf einen Blick, was du heute gegessen hast
*   **Sanfte Erinnerungen** (optional) - Freundliche Benachrichtigungen wie "Zeit für eine Pause?"
*   **Komplett kostenlos** - Keine Werbung, kein Abo, keine Datensammlung
*   **Barrierefreiheitsfokus** - Hoher Kontrast, einfache Benutzeroberfläche

🚀 Erste Schritte
-----------------

### Voraussetzungen

*   Flutter 3.0+
*   Android Studio / Xcode (für Emulatoren)
*   Ein physisches Gerät oder Emulator

### Installation

1\. **Repository klonen**:

    git clone https://github.com/addereum/mealbox.git
    cd mealbox

2\. **Abhängigkeiten installieren**:

    flutter pub get

3\. **App starten**:

    flutter run

### Release-Build erstellen

**Android:**

    flutter build apk --release

**iOS:**

    flutter build ios --release

📱 Wie man MealBox benutzt
--------------------------

1.  **App öffnen**, um das leere Tagesprotokoll zu sehen
2.  **Auf den großen runden Button tippen**, wenn du etwas isst
3.  **Mahlzeittyp auswählen** (Frühstück, Mittag, Abend, Snack)
4.  **Das war's!** Deine Mahlzeit wird mit der aktuellen Uhrzeit protokolliert
5.  **Historie ansehen** in der Liste unter dem Button

⚠️ WICHTIGER MEDIZINISCHER HINWEIS
----------------------------------

**MealBox ist KEIN medizinisches Werkzeug oder eine Behandlung.**

### Was MealBox IST:

*   Ein einfaches Tracking-Hilfsmittel
*   Ein Erinnerungstool
*   Ein Weg, Bewusstsein für Essgewohnheiten zu schaffen
*   Ein Open-Source Community-Projekt

### Was MealBox NICHT ist:

*   Ein Ersatz für professionellen medizinischen Rat
*   Eine Behandlung für Essstörungen
*   Ein Diagnosewerkzeug
*   Eine Gewichtsmanagement-App

### Konsultiere einen Facharzt, wenn:

*   Du mit gestörten Essmustern kämpfst
*   Du unbeabsichtigt Gewicht verlierst/zunimmst
*   Essen signifikante Belastung verursacht
*   Du persönliche Ernährungsberatung benötigst

🔒 Datenschutz & Sicherheit
---------------------------

*   **Keine Daten verlassen dein Gerät** - Alle Informationen werden lokal gespeichert
*   **Keine Internetverbindung nötig** - Funktioniert komplett offline
*   **Kein Tracking oder Analytics** - Wir sammeln keine Nutzungsdaten
*   **Jederzeit exportieren/löschen** - Du behältst die volle Kontrolle über deine Daten

🎯 Ziel der App
---------------

MealBox wurde entwickelt, um:

1.  **Achtsamkeit** für Essgewohnheiten zu schaffen
2.  **Erinnerungshilfe** zu bieten, ohne Druck
3.  **Daten** für Gespräche mit Fachleuten bereitzustellen
4.  Eine **wertfreie Zone** für Selbstfürsorge zu schaffen
5.  Die **Community** zu stärken, die mit ähnlichen Herausforderungen lebt
